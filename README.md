# Premier League 2026/2027

Aplicación web desarrollada con HTML, CSS y JavaScript para gestionar las alineaciones de los 20 equipos de la Premier League.

## Funcionalidades

- Selección de titulares haciendo click en su nombre.
- Suplentes automáticos.
- Formaciones estándar según el equipo.
- Guardado de alineaciones mediante LocalStorage.

Desarrollado por Manuel Enrique Bernal Gallego.
